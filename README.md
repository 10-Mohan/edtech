# 🚀 Waypoint AI: Adaptive Intelligent Learning Platform

> **Curriculum-Grounded Conceptual Learning, First-Principles Cognitive Science, and Real-World Career Navigation.**

Waypoint AI is a next-generation pedagogical platform connecting **Students**, **Educators**, and **Parents** around deep conceptual mastery. By combining Directed Acyclic Knowledge Graphs, SuperMemo SM-2 Spaced Repetition, Dual-Mode Socratic & Feynman AI Tutoring, and real-world Engineering Career Bridges, Waypoint eliminates rote memorization and empowers authentic understanding.

---

## 🌟 Key Features

### 🎓 1. Student Learning Hub
- **Interactive Knowledge Dependency Graph (DAG)**: Visualizes prerequisite chains across complex topics (Limits $\rightarrow$ Derivatives $\rightarrow$ Chain Rule $\rightarrow$ Optimization) with color-coded mastery status and node-specific remediation.
- **SM-2 Spaced Repetition Flashcards**: Active recall engine with 3D flip card animations, dynamic ease factor calculations, and review scheduling.
- **Dual-Mode Socratic & Feynman AI Tutor**:
  - *Socratic Inquiry*: Step-by-step guidance that leads students to first principles without spoon-feeding answers.
  - *Feynman Technique ("Teach Me")*: Students explain concepts in their own words; the AI grades clarity, pinpoints missing nuances, and provides structured feedback.
- **AI Homework Scanner & Error Pinpointer**: Parses multi-step algebraic derivations, isolates the exact step where an error occurred, and provides actionable remediation bridges.
- **Career Roadmap ("Why Am I Learning This?")**: Connects high school curriculum directly to high-impact engineering careers (3D Game Physics, AI Protein Folding, Robotics) with interactive on-the-job simulation challenges.
- **Adaptive Diagnostic Gap Assessment**: Pre-assessment engine that detects misconceptions and auto-generates personalized recall cards.

### 👩‍🏫 2. Teacher Orchestration Portal
- **Live Classroom Mastery Heatmap**: Matrix view tracking individual and cohort proficiency across all curriculum topics.
- **3-Tier Differentiated Worksheet Studio**: Generates Tier 1 (Scaffolded), Tier 2 (Standard), and Tier 3 (Advanced Proof & Extension) assignments in one click with export/print layout.
- **Cohort Misconception Radar**: Automatically groups students struggling with identical conceptual blockers for targeted interventions.

### 👨‍👩‍👧 3. Parent Portal & Family Bridge
- **Plain-Language Weekly Digest**: Converts cognitive learning metrics into actionable progress updates and milestone celebrations.
- **Dinner Table Conversation Starters**: Friendly, non-technical prompts connecting classroom learning to real-world phenomena.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/<YOUR_USERNAME>/<YOUR_REPO_NAME>.git
cd <YOUR_REPO_NAME>

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at `http://localhost:5173/`.

### Production Build
```bash
npm run build
```
